# 🎲 Kuri Draw Lots

**A simple and convenient way to select names randomly and fairly.**

Kuri Draw Lots is a digital lot-drawing application designed to make random selection easier, faster, and more convenient. It can be used for lucky draws, selecting participants, choosing winners, and other activities where random selection is needed.

## ✨ Features

* 🎯 **Random Selection** — Select a name or participant randomly.
* ⚡ **Quick and Easy** — Make the selection process simple and convenient.
* 🎨 **User-Friendly Interface** — Designed for an easy-to-use experience.
* 📱 **Convenient Access** — Use the application on supported devices.
* 🎉 **Multiple Use Cases** — Suitable for lucky draws, events, games, and group activities.

*Note: Keep only the features supported by the current implementation.*

